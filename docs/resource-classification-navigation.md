# Clasificación del recurso

El resumen de un nodo muestra Familia, Tipo y Subtipo desde el catálogo compartido de componentes. No utiliza el nombre editable del nodo para inferir su clasificación.

Doble clic en la clasificación (o Enter/Espacio con foco) abre Estándares en el componente correspondiente. Antes de cambiar la ruta se espera el guardado del editor; si falla, se conserva la edición abierta. Los invitados pueden consultar la clasificación pero no abrir la administración de estándares. Los elementos visuales sin clasificación conservan su presentación previa.

Validación: compilación de frontend, clasificación de todos los componentes activos, referencia de segmento de red y tipo inexistente; navegador sintético a 1440×900, 1024×768, 390×844 y 844×390, doble clic y teclado. Despliegue: resource-classification-20261026; copia de seguridad de base de datos y quadlet previa al reinicio.
